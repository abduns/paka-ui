## Icons

Hugeicons supplies the interface icon set. `@hugeicons/core-free-icons` and `@hugeicons/react` are MIT licensed and are the public default. `HUGEICONS_ICON_STYLE` can alias the free package to a Hugeicons Pro package at build time. Active sidebar items also import Solid Rounded icons through `@hugeicons/core-solid-rounded`, which Vite resolves to the optional `@hugeicons-pro/core-solid-rounded` package when it is installed. Using a Pro package requires your own Hugeicons license; without one, active items keep the stroke icons.
